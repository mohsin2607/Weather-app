# 🌤️ Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Shows current temperature
- 💧 Shows humidity
- 💨 Shows wind speed
- 📱 Responsive design
- 🌍 Supports cities around the world

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
